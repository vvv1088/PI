# Marketing Intelligent System — 用户操作手册(白话版)

> 给团队看。讲每个模块怎么用、按钮点了会发生什么。当前版本 = v14。
> 系统地址:部署后的 `ci.boostmarketing.site`(需 cPanel 密码 + 系统登录)。

---

## 0. 登录
- 打开网址 → 输入**用户名 + 密码** → 进入系统。
- 左下角显示你的名字 + 岗位。点 **Log out** 退出。
- 看得到哪些菜单、能不能增/改/删,由你的**岗位权限**决定(Admin 才看得到 Administration)。

---

## 1. PI · Planning Intelligence(规划)

> 流程**严格单向**:Idea(想法)→ Hypothesis(假设)→ Creative(素材)。下层不能凭空建,必须从上层延伸。

### 1.1 Idea Pool(想法池)
- **新增想法**:点「＋ 新增想法」→ 填一句话想法、来源、优先级、**Tag(必填,从 Hook 词表多选)** → 保存。提出人 = 你。
- **编辑 / 删除**:每行右边。
  - 「编辑」「删除」**只对自己提出的想法**显示;别人的、AI 拉的你动不了。
  - 「删除」只在**该想法还没立过假设**时出现(已立假设的删不了,保护下游)。
- **立假设**:点「立假设」→ 跳到 Hypothesis 表单,自动把这条想法带进去。
- **AI 想法**:标 `By AI` 的是系统每周从竞品情报自动拉的,Tag 也自动打;你不用管。
- **躺池提醒**:超过 60 天没处理的想法会红色提醒,月会处理(立假设 / 继续躺 / 归档)。

### 1.2 Hypotheses(假设)
- 入口**只有**从 Idea Pool 点「立假设」。不能直接新建。
- 表单分 4 块:① 基本(品牌/Format/类型/人群…)② 指标 ③ 假设(改变 X / 目标值 / 理由)④ 素材矩阵。右侧有 **Baseline(真实近30天数据)** 和 **容量体检**。
- **理由**:从想法自动带入、**锁定不可改**(要改回 Idea Pool 改想法)。你只填「改变 X」。
- **两个保存按钮**(右上角):
  - **Draft** = 存草稿,**没填完也能存**(慢慢补)。
  - **Save** = 完成。**必须所有项填齐**才能存;没填齐会把缺的项**标红 `*`** 并提示,存不进去。
- **Baseline 怎么看**:选了品牌 + 主指标,右侧自动显示该品牌**真实的近30天基准**(如 OK188KH 首存 周均27、CPA $24)。INZ9 的首存金额是 **RM(马币)**,其它是 **$**。
- **生成后**:在 Hypotheses 列表点开任一条 → 右上角有 **Edit / Delete**。
  - **Edit** = 改所有字段(团队刚上手填错可用)。
  - **Delete** = 只在**名下素材都还是空骨架(没填过版本)**时出现;有素材在用就删不了。
- 列表中间有 **Create Date** 列,显示创建时间。

### 1.3 Creatives(素材)
- 存假设(完成 → 待锁定)时,系统按素材矩阵**自动生成骨架素材行**(编号 `HYP-xxx-V1…`)。
- 每行:
  - 第1列 **Ads Code**:没填显示 `pending`;真正的 Ads Code 在 **Setup / Edit 表单里手动填**。
  - 第2列 **系统码**(`HYP-xxx-Vn`):可点 → 跳回它上层的 Hypothesis。
  - 最右:没版本 → **Setup**(填第一版:图 + 文案 + Ads Code + 状态);有版本 → **Edit**(改这版 / 换新版)。
- **换版留痕**:被拒重投 / 效果差 / 自发优化 → 都存成新一版,旧版保留,要选「为什么换」。
- ⚠️ 现阶段:在 Meta 改了素材,**也要回这里手动记一版**(系统暂不自动回传 Meta 的改动)。

### 1.4 Results(结果)
- 自动派生:有假设被判定(verdict)后,按来源 / hook / 视觉风格 / 指标聚合展示。没判定时是空的。

### 1.5 Dictionary(词表)
- 各类标签词条(Hook、人群、游戏类型…)的定义与启停。增删 / 启停权限 = 月度规划会。

## 2. CI · Competitor Intelligence(竞品情报)
- **Weekly Summary**:每周竞品报告。
- **Ads Library**:竞品广告库,可按市场 / 状态 / hook 等筛选。
- **Operators / Funnels**:竞品运营方 / 漏斗视图。
- **Pending List**:待确认的竞品候选。
- **Watchlist**:监测中的竞品关键词。
  - **Ad Status**:`Active`(近14天有广告)/ `Dormant`(15–30天)/ `Inactive`(>30天)/ `No ads`(库里没匹配到该词的广告数据)。
  - 「↻ rescan」= 立刻单独重抓某竞品(3–10 分钟)。

---

## 3. Administration(仅 Admin)
- **Roles & Permissions**:岗位 + 每个 section 的增/改/删权限开关。
- **Users**:增 / 改 / 删用户、重置密码、改用户名。
- **Activity Log**:所有增/改/删自动记录(谁、什么时候、改了什么)。

---

## 常见问题
- **Save 按不下去 / 字段标红 `*`**:有必填项没填完,补齐红星标的项再按 Save;或先按 Draft 存草稿。
- **删不掉假设 / 想法**:假设名下有在用素材、或想法已立假设,就删不了(保护下游);别人提的想法你也删不了。
- **Baseline 没显示真实数字**:刚登录数据还在拉,稍等或切一下品牌;若一直没有,可能是 Ads Raw Data 连接问题,找管理员。
- **改完没生效**:部署后记得**硬刷新**(Cmd+Shift+R)清缓存。
