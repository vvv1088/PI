# Marketing Intelligence System — 使用指南（User Guide）

> 给所有人看的白话版：每个页面干嘛、按钮点下去会发生什么、怎么用。
> 不需要懂技术。最后更新：2026-07-08

---

## 这套系统是干嘛的

| 模块 | 一句话 |
|---|---|
| **看对手（CI）** | 系统每周自动扒竞品在 Facebook 投的广告，AI 看懂每条（卖点/游戏/套路）整理给你，不用自己翻广告库 |
| **做测试（PI）** | 把想法变成正经 A/B 测试：想法 → 假设 → 素材 → 结果，全程有"裁判"保证测试干净（只变该变的），结论才可信 |

**打开方式**：浏览器进 dashboard 网址 → 登录（用户名+密码）→ 左边菜单分三组。闲置 10 分钟自动登出，重新登录即可。

# 一、COMPETITOR INTELLIGENCE（看对手）

| 页面 | 干嘛的 | 怎么用 / 要点 |
|---|---|---|
| **Weekly Summary** | AI 每周写好的竞品报告（USC/INZ9 两份），最常看的一页 | 上方选周、市场 tab 切换；报告 5 块（概况/重点 Operator/漏斗/创意/**本周值得测**）；Slack `#feed-ci` 周一收精简版，完整版在这页 |
| **Ads Library** | 看每一条对手广告（缩略图/卖点/风格/游戏类型/投了多久） | 筛选可叠加且联动（市场/Operator/Hook/Style/Format/Game Type/搜索）；顶部数字跟筛选变；Game Type 是 AI 看**画面**判的，可多值，旧数据可能显示 `-` |
| **Operators** | 按对手汇总（多少广告、主打什么） | 点对手名字 → 跳 Ads Library 自动筛出他全部广告 |
| **Funnels** | 对手把流量导去哪（Telegram 群/落地域名） | 按信号量排序（铺最开的在最上），链接可点 |
| **Pending List** | 系统关键词扫出来的**新对手候选**，等你确认 | 确认 = 正式监测；拒绝 = 去掉 |
| **Watchlist** | 正在监测的对手名单 | 开关 = 暂停/恢复；**Rescan** = 立刻单独重抓这一个（几分钟）；加竞品 = 手动加（品牌名+国家） |

# 二、PLANNING INTELLIGENCE（做测试）

> 核心流程：**想法 → 假设 → 素材 → 结果**。先有想法，立成可验证的假设，配素材去测，最后判定下结论。

## 1. Idea Pool（想法池）

| 操作 / 元素 | 说明 |
|---|---|
| 筛选 | 按来源筛（竞品情报/市场研究/内部数据/一线反馈/原创直觉）；可勾"显示已归档" |
| ＋新增想法 | 加一条你自己的想法（不绑品牌、Tag 不强制） |
| `AI` 徽章 | 每周一系统从竞品周报自动挑 2–3 条精华进来（来源=竞品情报） |
| 红色标记 | 躺超过 60 天，提醒月会处理 |
| 立假设 | → New Hypothesis 表单 |
| 归档 / 删除 | 归档=存档不删；删除仅限自己提的、且没衍生假设 |

## 2. New Hypothesis（立假设）

| 填什么 | 说明 |
|---|---|
| **品牌（先选）** | 自动锁定该品牌主指标+防守底线（例：OK188KH = 7-Day High-Value Rate / Day-1 Quality Floor），防填错口径；没选时基线显示"请先选择品牌" |
| 起因 / 证据 / 测试类型 / 人群 / 年龄段 | 证据可标"纯直觉"（合法，但单独统计胜率） |
| **顾客阶段** | 这次测试打漏斗哪一环（拉新/激活/留存/复购转化/唤回）；列表 Stage 列分色、可筛 |
| **预计上线日 + 测试周期(天)** | 日历选；右侧 Capacity Check 的「周期」自动取这里，不用填两遍 |

## 3. 素材管理 & 标签（对比页）

从 Hypothesis 详情抽屉点「素材管理 & 标签 →」进入。

**勾"本次测试维度"（最多 2 个：Format / Hook / 视觉风格 / Offer / 游戏类型）：**

| 勾几个 | 结果 |
|---|---|
| 1 个 | 单变量，自动给 **1 行**素材 |
| 2 个 | 交叉测，自动给 **4 行**（2×2） |
| 取消回 1 个 | 多出来的**空行**自动收回（已填内容的保留） |

**红色「内容不一致」提醒 = 裁判拦下，修好才能 Save：**

| 红条 | 意思 | 怎么修 |
|---|---|---|
| 勾了没差异 | 在测的维度素材之间还是一样，等于没测 | 让它变；**或用「变体名」（见下）** |
| 2×2 不齐 | 某维度超过 2 个值，或 4 种组合没凑齐 | 把多出来的改成另一个值补齐 |
| 被污染 | 没在测的维度混了不同值 | 去「🔒 全组锁定」设成统一值 |
| 素材不足 | 不够 2 条，凑不成对比 | 补素材 |

**Variant（07-08 新增）—— 在测维度每条素材必填，写清"这条素材具体是什么"：**

| 场景 | 怎么填 |
|---|---|
| 都是「游戏画面截图」，测三款不同游戏 | 视觉风格三行都选 游戏画面截图，每行 Variant 填游戏名（如 Boxing King (JILI)），**互不相同** |
| 都是「名人 Deepfake」，测不同名人 | 视觉风格都选 Deepfake，Variant 填人名（甄子丹 / Jackie Chan…），互不相同 |
| 取值本来就不同（分层红利 vs 免费注册） | Variant 也要填（当内容备注，列表一眼可读），可以相同（比如都用同一个 KOL） |
| 交叉测（勾 2 个维度） | 两列都填；**同一取值的素材 Variant 必须一样**，不然会被当成第 3 个值拦下 |
| Format 也一样填 | 写具体差异：时长（15s / 30s）、配色、版式等 |
| 省力技巧 | 打两三个字母自动提示用过的名字，直接点选；手打大小写不对系统会自动统一 |
| ⚠️ 不要再 | 往 Dictionary 加游戏名/人名当"视觉风格"——统计会失真，字典也会失控 |

**Draft / Save**：Draft = 随便改；**Save = 锁定**，锁定后只读、仅 Admin 能解锁。

## 4. Creatives（素材）

| 元素 / 操作 | 说明 |
|---|---|
| Setup / Edit | 没建首版显示 Setup，建过显示 Edit；同样 Draft（可改）/ Save（锁定） |
| **Schedule 列** | 自动继承所属假设的排期，显示倒数（还有 N 天开测 / 测试中剩 N 天 / 待判定） |
| **■ 结束运行** | 收掉一段投放，可选标记已下线 |
| **＋ 补记周花费** | 跑多周的每周补一笔，Budget「已投放」按周精确汇总 |
| 上传图片 | 自动压缩并存云端，不拖慢加载 |

## 5. Results（结果）+ 判定

| 步骤 | 说明 |
|---|---|
| 入口 | Hypotheses 打开假设 → 抽屉里「判定」按钮 |
| 填什么 | 结论（成立/不成立/无定论）+ 置信度（勉强不计胜率）+ **学到什么（必填）** |
| 之后 | 状态变「已沉淀」；Results 页自动出胜率；判定成立会问要不要转「主力运行」 |

## 6. Dictionary（术语字典）

系统所有标签的"标准取值表"（Hook/视觉风格/游戏类型/Offer/人群/指标/测试类型/**顾客阶段**…）。tab 切类别；下拉里能选什么由这里定义，月会按实际增删。

## 7. Budget Allocation（预算分配）

每月每品牌的预算：申请 → 核批 → 决策 → 留痕。

| 步骤 | 谁 | 做什么 |
|---|---|---|
| ① 申请 | Marketing 负责人（Joey/Bryan） | 填自己品牌的申请，**金额+理由必填** |
| ② 核批 | USC 负责人（Anna/JK/WenJie） | 填核批；**核批低于申请必须写原因** → 状态自动「待决策」+ Slack 通知 ZQ |
| ③ 决策 | ZQ | 点红色「决策」拍板（必填原因）→「已定」锁定；要改找 ZQ「重开」 |
| 留痕 | — | 每行「历史」看完整时间线；「已投放/使用率」自动算（来自素材周花费） |

> 谁能填哪格由 **Administration → Budget Permission** 配（仅 Admin）。

## 8. Monthly Overview（月度总览）

| 元素 / 操作 | 说明 |
|---|---|
| 品牌卡 | 每品牌一卡：预算 + 状态 + 该月排期假设 + 素材就绪 |
| 就绪度体检条 | 顶部一眼看哪些品牌还没准备好；可按品牌筛 |
| **确认发送** | 和 V 过完 meeting 后，**各品牌 Marketing 负责人自己按** → 该品牌 Slack 频道收到完整计划；有留痕，重发会提示 |

## 常见操作怎么做

| 我想… | 去哪 / 怎么做 |
|---|---|
| 看这周竞品在搞什么 | Weekly Summary（或等周一 Slack `#feed-ci`） |
| 立刻看某对手最新广告 | Watchlist 找到它 → Rescan，等几分钟回 Ads Library |
| 发现新对手想盯它 | Watchlist「加竞品」；或它已在 Pending List 就点「确认」 |
| 只看某类广告 | Ads Library 叠加筛选（市场/游戏类型/格式…） |
| 把一个想法变成测试 | Idea Pool「立假设」→ 选品牌填表 → 进「素材管理 & 标签」配素材、修红条、Save |
| 填这个月预算 | Budget Allocation → 自己品牌的行 → 点自己该填的格 → 金额+理由 → 保存 |
| 发下月计划到 Slack | Monthly Overview → 检查自己品牌卡就绪 → 确认发送 |
| 测试跑完下结论 | Hypotheses 打开该假设 → 判定 → 填结论+学到什么 |
| 给某人改密码 | Users → Reset PW → 直接输入新密码（别留空） |

## 几个要知道的预期（不是 bug）

| 现象 | 为什么 |
|---|---|
| 新加/重抓的对手，广告没"秒"出现 | 要后台抓取+AI 分析，等几分钟到十几分钟 |
| 游戏类型/视觉风格比文字情报晚出 | 画面分析是后台异步慢慢补的，刷新会越来越全 |
| 少数广告某些字段一直空 | 画面太长/抓取失败，系统后续自动重试补齐 |
| Slack 周报很短 | 那是精简版；完整的在 Weekly Summary 页 |
| AI 想法每周一才来几条 | 设计如此（精选、不刷屏），不是漏了 |
| 素材表红条不让 Save | 裁判在保护你——修掉它指出的不一致就能锁定 |
| Budget 格子点不动 | 不是你该填的格（分工见 Budget Permission），或该行已「已定」锁定（找 ZQ 重开） |
| 确认发送按钮灰的 | 只有该品牌的 Marketing 负责人能发 |
