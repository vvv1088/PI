# Marketing Intelligence System — 使用指南（User Guide）

> 给所有人看的白话版：每个页面干嘛、按钮点下去会发生什么、怎么用。
> 不需要懂技术。最后更新：2026-06-30

---

## 这套系统是干嘛的

它把两件事合在一个后台里：

- **看对手（CI）** —— 系统每周自动去扒竞争对手在 Facebook 投的广告，用 AI 看懂每条（打什么卖点、什么游戏、什么套路），整理好给你看，你不用自己翻广告库。
- **做测试（PI）** —— 把想法变成正经的 A/B 测试：想法 → 假设 → 素材 → 结果，全程有"裁判"帮你把测试做干净（只变该变的、锁住不该变的），结论才可信。

**打开方式**：浏览器进 dashboard 网址 → **登录**（你的用户名 + 密码）→ 左边菜单分三组，点不同菜单看不同内容。闲置 10 分钟会自动登出，重新登录即可。

# 一、COMPETITOR INTELLIGENCE（看对手）

## 1. Weekly Summary（每周总结）—— 最常看的一页
AI 每周自动写好的竞品分析报告，分柬埔寨（USC）和马来西亚（INZ9）两份。
- 上方**选周**看某一周；用**市场 tab** 切 USC / INZ9。
- 报告 5 块：① 整体概况 ② 值得注意的 Operator ③ 漏斗与投放模式 ④ 创意方向 ⑤ **本周值得测试的方向**（系统建议你可以试什么 + 参考哪个对手）。
> 同一份报告每周一会自动发**精简版到 Slack `#feed-ci`**（只有重点）。看完整的来这页。

## 2. Ads Library（广告库）—— 看每一条对手广告
每条对手广告：缩略图、品牌、卖点、画面描述、视觉风格、游戏类型、投了多久…
- **上方筛选器可叠加**：市场 / Operator / Hook / Style / Format / Game Type / 搜索框。
- **联动**：选了 KH，下面 Operator 列表只剩 KH 的；顶部数字跟着筛选变（筛选态标 `(filtered)`）；拉到底有"共 N 条，已全部显示"。
> **Game Type** 这列是 AI 看广告**画面**判的，一条广告可能同时多个类型（又体育又真人娱乐），显示多个标签；只有新扫到/分析过的才有，旧的可能显示 `-`。

## 3. Operators（对手总览）
按对手汇总：每个对手多少广告、主打什么。点对手名字可跳到 Ads Library 并自动筛出他的全部广告。

## 4. Funnels（漏斗总览）
看每个对手**把流量导去哪里**（Telegram 群、落地域名）。按信号量排序（铺得最开的排最上），链接可点。

## 5. Pending List（待确认候选）
系统定期用关键词扫 Facebook，**自动发现你还没监测的新对手**，放这里等你确认。
- **确认** = 正式加入监测，以后每周都抓它。
- **拒绝** = 不是你要盯的，去掉。

## 6. Watchlist（监测名单）
你正在监测的所有对手。
- **开关** = 暂停/恢复监测（关掉不再抓，但历史还在）。
- **Rescan（重抓）** = 不等周一，**立刻单独重抓这一个对手**最新广告（几分钟后更新）。
- **加竞品** = 手动加新对手（品牌名 + 国家）。

# 二、PLANNING INTELLIGENCE（做测试）

> 核心流程：**想法 → 假设 → 素材 → 结果**。一句话：先有个想法，立成可验证的假设，配几条素材去测，最后看结果下结论。

## 1. Idea Pool（想法池）
所有想法都先丢这。想法**不绑品牌**、Tag 不强制。
- 上方可按**来源**筛（竞品情报 / 市场研究 / 内部数据 / 一线反馈 / 原创直觉），可勾"显示已归档"。
- **＋新增想法** = 加一条你自己的想法。
- **AI 想法**：每周一系统会从竞品周报里自动挑 2–3 条"精华"放进来，带 **`AI` 徽章**（来源标"竞品情报"）。这是系统替你从对手情报里提炼的可测方向。
- 想法躺超过 60 天会标红，提醒月会处理（立假设 / 继续躺 / 归档）。
- 每条想法可：**立假设**（→ New Hypothesis）、**归档**（存档不删）、**删除**（仅限自己提的、且没衍生假设）。

## 2. New Hypothesis（立假设）—— 把想法变成可验证的假设
点想法的"立假设"或从 Hypotheses 页新建。
- **先选品牌** → 系统**自动锁定该品牌的主指标和防守底线**（例：OK188KH 主指标 = 7-Day High-Value Rate，防守底线 = Day-1 Quality Floor）。不同品牌口径不同，锁定是为了防填错。
- 填：起因、证据、测试类型、人群、年龄段。证据可标"纯直觉"（合法，但会单独统计胜率）。
- 没选品牌时基线会显示"请先选择品牌"。

## 3. 素材管理 & 标签（对比页）—— 给假设配素材、保证测试干净
从 Hypothesis 详情抽屉点「素材管理 & 标签 →」进入（进去时抽屉会自动收起）。
- **本次测试维度**（最多勾 2 个：Format / Hook / 视觉风格 / Offer / 游戏类型）：
  - 勾 **1 个** = 单变量，自动给你 **1 行**素材。
  - 勾 **2 个** = 交叉测，自动给你 **4 行**（2×2）。
  - 取消勾选回 1 个时，多出来的空行会自动收回（已经填了内容的行会保留，不会被删）。
- **🔒 全组锁定**：没在测的维度，在这里一次设好，表格里全组统一、不可改（保证只变在测的维度）。
- **红色「内容不一致」提醒** = 裁判发现测试不干净，告诉你哪里要修，**修好才能 Save 锁定**。几种情况：
  - *勾了没差异* —— 在测的维度，素材之间还是一样，等于没测 → 让它变。
  - *2×2 不齐* —— 交叉测里某个维度有 3 个以上的值，或 4 种组合没凑齐 → 把多出来的改成另一个值补齐。
  - *被污染* —— 没在测的维度混了不同值 → 去"全组锁定"设成统一值。
  - *素材不足* —— 不够 2 条，凑不成对比。
- **Draft / Save**：Draft = 随便改；**Save = 锁定**，锁定后只读、仅 Admin 能解锁回 Draft。

## 4. Creatives（素材）
所有素材在这，能看它的版本和投放回合。没建首版的显示 **Setup**，建过的显示 **Edit**。同样是 **Draft（可改）/ Save（锁定）** 的逻辑。

## 5. Results（结果）
汇总每个假设测完的结论。

## 6. Dictionary（术语字典）
系统所有标签的"标准取值表"（Hook、视觉风格、游戏类型、Offer、人群、指标、测试类型…）。用 tab 切换不同类别。这里定义了下拉里能选什么，**月会按实际增删**。

# 三、ADMINISTRATION（管理，仅管理员可见）

## 1. Roles & Permissions（角色权限）
权限**按角色 × 模块 × 动作（增/改/删）**设，不是按人设。五个人同一套权限 = 同一个角色。
- **新增角色 / 编辑** = 勾选这个角色在每个模块能不能 增 / 改 / 删。
- **Duplicate（复制）** = 拿现成角色改个名快速建新角色。
- **Delete** = 删角色（还有人用这个角色时会拦住，要先把人改到别的角色）。

## 2. Users（用户）
每个用户分配一个角色，权限跟角色走。
- **＋New User** = 建用户（用户名 + 姓名 + 角色，初始密码默认 123123，可改）。
- **Edit** = 改姓名 / 角色 / 用户名。
- **Reset PW** = 重置某人密码。**⚠️ 弹窗里是空的，请直接输入新密码**（至少 4 位）——不要留空确认。
- **Delete** = 删除用户（连登录一起删）。

## 3. Activity Log（操作日志）
谁、什么时候、对哪个模块做了什么（登录/登出、增/改/删）都自动记在这，可追溯。

## 常见操作怎么做

**看这周竞品在搞什么** → Weekly Summary（或等周一 Slack `#feed-ci`）。
**立刻看某对手最新广告** → Watchlist 找到它 → Rescan，等几分钟回 Ads Library。
**发现新对手想盯它** → Watchlist「加竞品」，或它已在 Pending List 就点「确认」。
**只看某类广告**（只看 MY / 只看体育 / 只看视频）→ Ads Library 叠加筛选。
**把一个想法变成测试** → Idea Pool 点「立假设」→ 选品牌填表 → 进「素材管理 & 标签」配素材、勾维度、修红条、Save。
**给某人改密码** → Users → Reset PW → 直接输入新密码（别留空）。

## 几个要知道的预期（不是 bug）

- **新加/重抓的对手，广告不会"秒"出现**：要后台抓取 + AI 分析，等几分钟到十几分钟。
- **广告的"游戏类型/视觉风格"会比文字情报晚一点出**：画面分析是后台异步慢慢补的，刷新会越来越全。
- **少数广告某些字段一直空**（画面太长/抓取失败）：系统后续自动重试补齐。
- **Slack 收到的周报是精简版**（point-form 重点）；完整的来 Weekly Summary 页。
- **AI 想法每周一才来几条**：这是设计（精选、不刷屏），不是漏了。
- **素材表红条挡着不让 Save**：是裁判在保护你——把它指出的不一致修掉就能锁定。

## 2026-07-08 更新:新功能白话指南(v32–v61)

### New Hypothesis 表单多了三个字段
- **顾客阶段**:这次测试打漏斗哪一环(拉新/激活/留存/复购转化/唤回),列表有 Stage 列可筛可看(分色)。
- **预计上线日**(点日历选)+ **测试周期(天)**:排期用;右侧 Capacity Check 的「周期」自动取这里,不用填两遍。

### 假设列表 / 判定
- 首列:💡想法编号在上、假设在下;月份筛选自动跟数据走。
- 抽屉里新增 **「判定」按钮**:测试跑完填 结论(成立/不成立/无定论)+ 置信度(勉强不计胜率)+ 学到什么(必填)→ 状态变「已沉淀」,Results 页自动出胜率;判定成立会问要不要转「主力运行」。

### Creatives
- **Schedule 列**:自动继承所属假设的排期,显示倒数(还有 N 天开测/测试中剩 N 天/待判定)。
- 素材概览新增 **「■ 结束运行」**(收掉一段投放,可选标记已下线)和 **「＋ 补记周花费」**(跑多周的每周补一笔,Budget 已投放按周精确汇总)。
- 上传图片自动压缩并存到云端(不再拖慢加载)。
